CAMPUS CONNECT — SESSION 1

Open this CampusConnect folder in Android Studio, allow Gradle sync to finish,
select the app run configuration and an Android emulator, then click Run.
Use JDK 17 or newer (Android Studio's bundled JDK is recommended).
The project uses Android SDK 37, Gradle 9.6.0, and Android Gradle plugin 9.4.1.
Android Studio may prompt you to install the SDK.

What was recreated
- Kotlin / Jetpack Compose application, package com.example.campusconnect.
- Campus Connect title and resources-for-international-students subtitle.
- Three cards with name, category, hours, and last-update date.
- Default English strings and Spanish (Mexico) strings in values-es-rMX.
- String resource IDs in CampusResource and formatted labels via stringResource.
- MainActivity registered as the launcher activity, including the class's final fix.

To test the class demonstration
1. Run with the device language set to English.
2. In the emulator's Settings, change the system language to Spanish (Mexico).
3. Reopen CampusConnect: names, categories, subtitle, and labels appear in Spanish.
4. Change back to English and reopen the app.
No in-app language selector was built in this session.
